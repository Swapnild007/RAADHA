# RADHA

RADHA is a unified AI workspace: one intelligence, many capabilities.

## Product foundation
- Mobile-first responsive React/Vite frontend
- Original light premium design system
- Home / Chats / Create / Library navigation
- Unified composer with Auto/Web/Files/Create modes
- Componentized interaction foundation
- Vercel-compatible static frontend

Provider integrations are intentionally not connected yet. The next phase adds the unified RADHA API and provider adapters behind the UI contract.
